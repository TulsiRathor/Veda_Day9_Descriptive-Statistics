# Titanic Dataset – Descriptive Statistics

## Project Overview
This project focuses on performing descriptive statistical analysis on the Titanic dataset using Microsoft Excel. The objective is to understand passenger data through statistical measures and interpret data distribution and variability.

## Dataset
- Dataset: Titanic Dataset
- Source: Kaggle
- Selected numerical variables:
  - Age
  - Fare
  - SibSp
  - Parch
  - Pclass

## Tools Used
- Microsoft Excel

## Statistical Analysis Performed
The following statistical measures were calculated:

- Mean
- Median
- Mode
- Standard Deviation
- 25th Percentile (P25)
- 50th Percentile (P50)
- 75th Percentile (P75)
- Skewness
- Interquartile Range (IQR)

## Key Insights
- Age distribution is slightly positively skewed.
- Fare distribution is strongly positively skewed.
- SibSp and Parch contain many zero values.
- Pclass shows a slightly negatively skewed distribution.
- Fare has considerable variation compared with the other selected variables.

## Project Files
- `Veda_Day9_Descriptive_Statistics.xlsx` – Excel workbook containing the raw dataset, descriptive statistics, and interpretation.

## Conclusion
This project helped develop practical skills in descriptive statistics, Excel formulas, data interpretation, and understanding data distribution and spread.
